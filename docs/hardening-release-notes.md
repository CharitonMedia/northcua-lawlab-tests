# NorthCUA Web fixes and before/after evidence

Final Nano configuration on one RTX 3090:

- Six original browser tasks: 6/6 fully completed and independently verified, versus 3/6 initially.
- Original canvas probe: 1/1, using the backend coordinate policy.
- Four additional task variations: 4/4, including a changed layout and 1440×900 viewport.
- Nine regression tests and four scripted integration controls passed separately.

The public evidence set preserves 41 real-model task runs, all unsuccessful stages, continuous WebM recordings, request/response captures, screenshots, source pins and patches. The two MP4 assets are real-time viewing copies.

[Read the analysis](https://github.com/CharitonMedia/northcua-lawlab-tests/blob/main/docs/hardening.md) · [Patched source](https://github.com/CharitonMedia/northcua-lawlab-tests/tree/harness-patched)

The initial configuration used NexAU's generic fallback system prompt. V3 loads the intended Web instructions. The study also records coordinate mapping, date recovery, repeated-cycle detection and an optional visible-receipt completion gate. These results describe a small synthetic task set.
