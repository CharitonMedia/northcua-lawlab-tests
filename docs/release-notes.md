# NorthCUA-Nano local experiments, November 13, 2026

Twelve real-model task runs on one RTX 3090, with continuous browser recordings, full traces and independent saved-state checks.

- Six baseline DOM-assisted tasks: three fully completed; four saved correct values.
- Two date-format failures, a repeated settings-tab loop, and a false completion in an unadapted visual probe.
- Three ISO-hint form completions and a separate successful coordinate-adapted visual run.
- Complete synthetic fixtures, serving settings, model hashes, source pins and reproduction instructions.

Read [the analysis](https://github.com/CharitonMedia/northcua-lawlab-tests/blob/main/docs/analysis.md). The three MP4 files are real-time transcodes; every original WebM is in the repository and evidence archive. The archive also includes screenshots, model calls and unsuccessful attempts.

These are small local browser experiments, not published-benchmark reproductions. Native Desktop, Mini, Hermes and Grok Bot haven't been accepted in these tests.
